# Mayur Patil - Portfolio (React + Vite + Tailwind)

1. `npm install`
2. `npm run dev`  (open the local link)
3. Replace `public/profile.jpg` with your photo, add `public/resume.pdf`
4. Edit your email and links in `src/data.js`
5. Contact form: create a free EmailJS account, add a service and a template
   (template variables: `from_name`, `reply_to`, `message`), then copy `.env.example` to `.env` and fill the 3 keys
6. Deploy: push to GitHub, import on vercel.com, and add the 3 `VITE_EMAILJS_*` values under Environment Variables
